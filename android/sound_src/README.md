# Sound sources

The full-quality CC0 source recordings (≈80 MB of FLAC) are not committed.
`manifest.json` lists every source file with its BigSoundBank / Freesound id and URL;
download them into `sound_src/v3/` and run `python3 scripts/process_sounds_v3.py` to
regenerate `app/src/main/res/raw/*.wav`. The processed WAVs are already in the repo.
