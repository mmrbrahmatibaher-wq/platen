# Platen — web

Plain HTML/CSS/JS port of the Platen Android app (v3.2). No build step, no dependencies.

```bash
python3 -m http.server 8080   # then open http://localhost:8080
npm test                      # node --test, 52 tests
```

See the [main README](../README.md) for features, GitHub Pages deployment, browser support and credits.
